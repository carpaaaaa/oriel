**Oriel is Search, for Windows.** Installed copies update to this on their own.

## Fixed

- **Bringing in bookmarks from a signed-in Chrome.** A Chrome signed in to a Google account keeps its bookmarks in a file of their own (AccountBookmarks), apart from the local one, which can be empty or missing: Oriel read only the local file and found none to bring in. It now reads both and brings each bookmark once.
- **Downloads.** On a completed download, a long site name or bigger text no longer runs under the Show in File Explorer and Remove buttons: the site's name is cut with an ellipsis and the time always stays.

Oriel isn't code-signed yet, so updates are checked only by their checksum from GitHub; see "Security" in the README.

## Install

`Oriel-Setup-0.1.29-x64.exe` for most PCs, `…-arm64.exe` for Snapdragon PCs (`Oriel-Setup-0.1.29.exe` holds both). On "Windows protected your PC" choose **More info**, then **Run anyway**.
