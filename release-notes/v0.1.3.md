**Oriel is Search, for Windows.** Installed copies update to this on their own.

## Security

From a full review of the code:

- Oriel's own interface can no longer be led away to a web page, and only Oriel's own interface can give it commands. A link or file dropped on the column opens in a tab.
- Websites can no longer open Oriel's own pages (`oriel://settings`, passwords, history) with a pop-up, a link or a redirect.
- The testing tools built into the source are switched off in the installed app.
- An extension's blocking rule can no longer freeze the browser with a runaway pattern (patterns are checked the way Chrome does).
- Settings and extension files are always written whole, so a crash can't leave one half written.

## Also

- The portable version says to download the new one instead of trying to update itself.
- The full list of licenses inside the app is complete.
- Releases now go out only after the Windows tests pass.

Oriel isn't code-signed yet, so updates are checked only by their checksum from GitHub; see "Security" in the README.

## Install

`Oriel-Setup-0.1.3-x64.exe` for most PCs, `…-arm64.exe` for Snapdragon PCs (`Oriel-Setup-0.1.3.exe` holds both). On "Windows protected your PC" choose **More info**, then **Run anyway**.
