**Oriel is Search, for Windows.** Installed copies update to this on their own.

## New

- **Sites can't tell the ad blocker is on.** Pages that put up a wall asking you to turn off your ad blocker (“Adblocker detected”) no longer see it: what Oriel blocks looks to the page as if it had loaded, and the empty test boxes sites use to look for a blocker stay in place. The ads and trackers are still blocked, and nothing more reaches them. It's on by default, in Settings › Privacy › Blocking › Hide the blocker from sites; if a site misbehaves, turn it off there, or stop blocking on that site alone (right-click its tab › Stop Blocking Ads on This Site). Pages made to test an ad blocker still get the truth.
- **Downloads say how fast and how long.** Each file coming in shows how far it is (a bar the row's width and the percent), its speed and the time left; the card's head and the downloads button's tooltip say the same for everything at once. Each file wears its kind (ZIP, PDF, EXE…), and finished ones show their size.
- **You see a download start.** The downloads card opens by its button for a few seconds as a file starts coming in, and goes by itself unless the pointer is on it. It never covers anything else open there and never takes the keys from the page. Settings › General › Downloads › Show downloads as they start turns it off.
- **The card by the button is how Downloads open**, sized to what it holds, with a button to open them in a tab. In a tab is still there, in Settings › General › Downloads › Open Downloads.

## Fixed

- **The downloads card follows the files as they come.** It stayed as it was when it opened: a file starting or finishing while it was open didn't show until it was opened again.
- Clearer buttons in the downloads list: Pause, Resume, Try again and Cancel by each file coming in, Show in File Explorer and Remove from list (the file stays) by each finished one.

Oriel isn't code-signed yet, so updates are checked only by their checksum from GitHub; see "Security" in the README.

## Install

`Oriel-Setup-0.1.33-x64.exe` for most PCs, `…-arm64.exe` for Snapdragon PCs (`Oriel-Setup-0.1.33.exe` holds both). On "Windows protected your PC" choose **More info**, then **Run anyway**.
